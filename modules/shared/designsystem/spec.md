# shared/designsystem

## Overview

Provide values generated from `specs/tokens` and common UI components built on them.

Located in `modules/shared/designsystem`. Only `core/utils` and `core/extensions` dependencies are allowed, and only when used. Do not depend on other shared modules, features, networking, or storage. Other `shared/*` modules must not depend on designsystem either.

## Public API

| Name | Behavior |
| --- | --- |
| `Tokens` | Color and spacing constants generated by `tools/generate.ts`; do not edit by hand |

## Common UI

Provide LoadingIndicator, EmptyState, ErrorState, and StatusBadge. Errors include accessible text and a retry action. Badges communicate state through text as well as color. Text sizes follow OS settings.

RepositoryRow receives RepositoryRowData (string and numeric display values only) and image-loading behavior, sharing row rendering across search, details, and saved lists. It does not depend on API models or persistence. Use a fallback when image loading fails.

## Theme

Screens and system bars follow OS light/dark settings, preserving contrast between backgrounds, text, and icons. Reflect OS theme changes while the app is running.

## Platform differences

The iOS module is `DesignSystem`, with implementation in `Sources/Shared/DesignSystem` and tests in `Tests/Shared/DesignSystem`. The Android package is `com.example.shared.designsystem`.

On iOS 26 and later, gate Liquid Glass components with `#available` and keep them inside this module.

- iOS uses standard SwiftUI background/text colors and automatic system-bar appearance changes.
- Android's app assembly selects Material 3 light/dark colors consistent with `enableEdgeToEdge()` system-bar appearance. The launch-window theme also switches through `values` / `values-night`.
- Before a row image loads, iOS displays a person icon and Android displays the owner's initial. Stars use an icon on iOS and a text label on Android.

## Localization

Callers provide LoadingIndicator's label, ErrorState's retry label, and RepositoryRow's star-count/saved labels. Do not embed UI text or depend on core/localization internally.
